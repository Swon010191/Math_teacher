theo tung commit.

  Foundation, da phat hanh tai commit `8f64659` (release `v1.0.0`).

## Quy uoc cap nhat

Khi co mot dot cai tien lon tiep theo, tao `VERSION_3.md` va mo ta su khac biet
so voi Version 2. Khong tao mot version moi chi vi co commit sua nho, dinh dang
lai code hoac cap nhat tai lieu khong lam thay doi dang ke san pham.

Moi file phien ban can ghi ro:

1. Moc bat dau va trang thai commit.
2. Project co nhung chuc nang gi tai moc do.
3. Thay doi lon so voi phien ban truoc.
4. Loi da sua va anh huong den nguoi dung.
5. Bang chung kiem thu.
6. Han che con lai.
